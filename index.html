Comment ça marche

    Installer l'annuaire sur votre téléphone

    iPhone : ouvrez ce lien dans Safari, touchez le bouton Partager, puis « Sur l'écran d'accueil ».

    Android : ouvrez ce lien dans Chrome, touchez le menu (trois points), puis « Ajouter à l'écran d'accueil ».

    Les coordonnées sont visibles par tous les présidents connectés, en lecture seule : seul le président de l'association et le coordinateur peuvent les modifier. Ne les saisissez qu'avec l'accord de la personne.

    Districts et référents

    Le chef-lieu relie les villes du district sur la carte.

    Propositions à valider

    Codes d'accès des présidents

    Chaque président reçoit son propre code. Envoyez-lui le message d'invitation par WhatsApp ou par e-mail. Votre code coordinateur reste dans l'onglet « Accès » du tableur.

    Ajouter une association

    Un code d'accès sera créé automatiquement pour son président.

    Pour une association nationale, indiquez son sigle ou un nom court : il sert de titre à la fiche. Le nom complet se remplit ensuite dans la fiche.

    Mon accès

    Sur un ordinateur partagé, pensez à vous déconnecter après usage.
